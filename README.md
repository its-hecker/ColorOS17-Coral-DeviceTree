# ColorOS 17 coral device adaptation

Maintainer: **Hecker**. Experimental **coral device compatibility overlay** for a ColorOS 17 binary port, referencing the existing HeckerOS floral Android 17 device tree.

This repository does not replace the complete device tree yet. The first development branch contains source provenance, hardware audits and notes. The original floral hardware stack remains authoritative until a tested ColorOS-specific replacement exists. Do not flash.
